# Shubham Portfolio

A modern, responsive portfolio website built with Next.js, Tailwind CSS, and Framer Motion. This project showcases my work, experience, skills, and contact information in a polished single-page experience.

## Overview

This portfolio is designed to feel sleek, fast, and immersive while staying simple to navigate. It includes:

- A strong hero section with animated introductions
- A professional About section
- Experience and project highlights
- Skill showcases
- A contact section with form support
- Smooth scrolling and modern motion effects

## Tech Stack

- Next.js 16
- React 19
- Tailwind CSS
- Framer Motion
- TypeScript
- Resend API for contact form handling

## Features

- Responsive layout for desktop, tablet, and mobile
- Smooth scrolling and animated section transitions
- Modern glassmorphism-inspired cards and UI elements
- Clean and professional portfolio structure
- Contact form integration for inquiries

## Project Structure

```bash
app/                 # Main app routes and page layout
components/          # Reusable UI components
public/              # Static assets
```

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js 18+
- npm or pnpm or yarn

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open http://localhost:3000 in your browser.

## Build for Production

```bash
npm run build
```
